CourseLM 使用说明

需要 Python 3.11+ 和可访问 NotebookLM 的网络。
安装与浏览器配置见 README.md。

1. 首次运行 courselm login，完成 Google 登录。
2. 将课程资料放到 courses/<课程名>/。
3. 运行 courselm generate <课程名>。

Markdown 与 LaTeX 源码保存在 output/<课程名>/。
安装 XeLaTeX 并加入 PATH 后，生成时自动导出 PDF。
只需要 Markdown：courselm generate <课程名> --no-pdf
离线重新导出 PDF：courselm export-handout <课程名>

失败后重跑同一生成命令即可续跑。
Obsidian 同步可选，默认关闭，在 config/config.yaml 中配置。
登录态仍保存在 user_data/。本版不再提供 GUI 或 Portable 构建。
