# 蜂考突击课讲义风格特征提炼与提示词设计规范

## 一、背景与设计目标

突击课（以“蜂考突击课”为代表）在高校期末复习群体中得到了广泛验证，其核心优势在于**极度聚焦应试**、**零认知冗余**、**结构化模板化**与**即学即练的反馈闭环**。

传统高校教材或学术讲义往往遵循“严格公理体系 → 冗长定理推导 → 抽象定义 → 综合大题”的逻辑，对考前自学或期末突击极不友好。而蜂考突击课讲义则逆向重构了认知链路：
**考情分值明确 → 极简核心考点 → 必背速记口诀 → 典型极简题型带练 → 避坑失分提醒 → 趁热打铁过关**。

本规范的目标是：通过系统提炼“突击课”文件夹内全学科（数学、物理、计算机、电子电气、机械力学、经济学等）实战讲义的形式与内容特征，将其转化为标准化的提示词系统与渲染规范，确保 CourseLM 在输入任何课程资料时，均能稳定生成结构一致、质量过硬、形式完全对齐蜂考突击课的高分期末自学讲义。

## 二、蜂考突击课核心特征深度提炼（7大黄金法则）

基于对《突击课》目录下数十门经典课程讲义（包括高数、线代、概率论、C语言、操作系统、数据结构、电路、电磁学、微观经济学等）的深度切片与文本分析，提炼出蜂考讲义的 7 大核心特征法则：

### 1. 【课时化高效切片】(Lesson-based Pacing)
- **特征**：摒弃厚重晦涩的“章-节-目”学术编排，采用“课时一、课时二、……”的实战切片方式。
- **作用**：每个课时对应一个 2~3 小时可独立攻克的复习单元，让学生在短时间内获得高确定性的进度感与掌控感。

### 2. 【考情速览与分值透明】(Exam Radar & Score Matrix)
- **特征**：每个课时开头第一页，强制放置【考情速览】矩阵表格：
  | 考点 / 题型 | 重要程度 | 预计分值 | 常见题型 |
  | :--- | :--- | :--- | :--- |
  | 考点一：... | 必考 / ★★★★★ | 8~12分 | 计算题、大题 |
  | 考点二：... | ★★★ | 3~5分 | 选择题、填空题 |
- **作用**：在动笔前直接建立分值预期，标明“必考”、“★★★★★”星级与考查题型（选择/填空/计算/证明/大题），辅以 1~2 句白话突击提分策略，指导复习优先级。

### 3. 【最小知识集与速记口诀】(Minimal Concept & Mnemonics)
- **特征**：
  - 坚决删除所有繁琐的历史背景、哲学探讨与冗长推演；
  - 只保留解题所必需的定义、公式、符号含义与适用条件；
  - **提炼朗朗上口的速记口诀或解题心法**（如概率论德摩根律：“*长杠变短杠，开口换方向*”；线代行列式：“*对应成比例，值为零*”；C语言：“*大括号位置不影响执行*”；极限计算：“*等价代换抓乘除，加减展开用泰勒*”）。
- **作用**：大幅降低初学者的记忆阻力，使关键定理变为下意识的应试动作。

### 4. 【典型极简例题紧随】(Immediate Example Coupling)
- **特征**：
  - 不搞“理论集中轰炸、习题堆积在后”；
  - 核心考点讲完，立即紧跟 1~2 道最轻量、计算负担最小、最能展现核心招式的“标准例题”（题1、题2）；
  - 严格标明真实来源：`[真题·年份]`、`[老师题库]`、`[作业原题]`、`[教材例题]`、`[必要补充]`。
- **作用**：趁热打铁，让概念在第一分钟就与真实考题形成神经联结。

### 5. 【保姆级分步解题与避坑指南】(Structured Steps & Pitfall Warnings)
- **特征**：
  - 计算题与大题严格按编号步骤输出：**步骤一、步骤二、步骤三**；
  - 每一步清楚交代“这一步做什么、依据什么公式、怎么代入计算”，绝不跳步；
  - 选择题与填空题直接给【答案】+【考场解析】，剖析混淆概念（如并发与并行、系统调用与库函数）；
  - 配备【避坑提醒】：直击考场阅卷扣分点（定义域漏写、符号看错、边界条件漏讨论等）。

### 6. 【趁热打铁独立练习闭环】(Practice & Mastery Loop)
- **特征**：
  - 题型内设置【自己试】：与标准例题高保真同构（通常只换数字或外层包装），提供不剧透答案的“起步提示”，并以独立四级标题 `#### 解答` 提供分步答案与自检说明；
  - 课时末尾设置【课时过关练习】：精选 2~3 道覆盖全课时重点的综合题，同样配备提示、独立 `#### 解答` 与做错回看指引。
- **作用**：确保学生脱离例题后依然能独立拿分，形成“学-练-评”闭环。

### 7. 【排版清爽与公式规范】(Typeset Aesthetics)
- **特征**：标准 LaTeX 公式（行内 `$...$`、独立块 `$$...$$`），清晰统一的二级/三级标题层级，避免花哨的营销词和混乱的代码块，兼顾 Obsidian 电子阅读与 A4 双面打印交付。

## 三、提示词架构体系设计

根据上述特征，对 CourseLM 的三大提示词（大纲分析、绪论指引、章节生成）进行重构升级：

### 1. 课程大纲生成提示词 (`planning.course_outline`)
- **设计逻辑**：引导大模型通读课程全部资料后，提炼出面向期末考点的 6~10 个冲刺课时，合并学术重叠章节，确保每个课时均可独立闭环。

### 2. 绪论与使用说明提示词 (`global.introduction`)
- **设计逻辑**：生成《期末突击自学讲义使用说明（突击课版）》，讲清“考情速览知权重 → 核心考点背口诀 → 标准例题跟步骤 → 避坑提醒防丢分 → 独立练习验真伪”的学习心法，并提供考前 24~72 小时冲刺时间分配方案。

### 3. 课时/章节生成提示词 (`dynamic.chapter`)
- **设计逻辑**：严格强制蜂考结构规范，模板如下：
  ```markdown
  # 第{chapter_index}章 {chapter_title}

  ## 考情速览
  | 考点 / 题型 | 重要程度 | 预计分值 | 常见题型 |
  | :--- | :--- | :--- | :--- |
  | 1. ... | 必考 / ★★★★★ | ...分 | ... |
  （提分策略：1~2句白话指明核心拿分路径与优先攻克点）

  ## 题型一：具体题型名称
  ### 核心考点与速记口诀
  （极简概念、必背公式、适用条件、好记实用的速记口诀/解题心法）
  ### 标准例题
  （计算负担最小的经典题，标明来源 [真题·年份] 等）
  ### 跟着做
  （编号步骤规范解答，计算与公式代入步步清晰）
  ### 避坑提醒
  （考场易错点、扣分陷阱与关键辨析）
  ### 自己试
  （同构独立练习题，先给启发提示）
  #### 解答
  （规范步骤、答案及易错自查）

  （按需编写后续题型……）

  ## 课时过关练习
  （2~3道综合过关练习题，附提示与独立四级标题：）
  #### 解答
  （完整分步解答与做错回看指引）
  ```

## 四、系统配套适配与兼容性保障

1. **章节格式校验器 (`validate_chapter_markdown`)**：
   - 完美兼容 `## 考情速览` 与 `## 本章路线`；
   - 兼容 `## 题型...` 与 `## 考点...`；
   - 兼容 `### 核心考点与速记口诀`、`### 标准例题`、`### 跟着做`、`### 避坑提醒`、`### 自己试`；
   - 兼容 `## 课时过关练习` 与 `## 章末过关`。
2. **例题索引提取器 (`question_index.py`)**：
   - 扩展正则，自动提取标准例题与典型例题，生成附录索引。
3. **LaTeX 编译器 (`latex_renderer.py`)**：
   - 优化表格排版，使 4 列表格（考情速览表）以美观规范的 `longtable` 在 A4 版面上自适应呈现；
   - 将 `考情速览`、`课时过关练习` 等无编号小节与正文层级精准渲染。
