## 准入约定

`FigureBinding` 固定当前 task、文档相对路径、题目 hash、asset/source hash、页码与 bbox、来源文件位置和图注。绑定只通过明确选定某题与某图的服务端操作建立，LLM 和文字相似度不生成批准。编辑器选图这一步即为绑定操作，不增加逐张审核流程；相同绑定在后续构建自动复用。

Markdown 解析使用 CommonMark + table + math + frontmatter；题图只落在完整顶层题干块末尾，解答/提示之前。表格、数学、代码和列表中的选图位置拒绝；旧图先按语法节点省略，不修改原文字，不在语法不可确认处猜位置。重复运行结果相同。对任意无法定位或不支持的图语法阻断该文档处理，不能原样放过。

不完整/缺图与来源错误分开报告。正文省略的图附“配图待补”提示；不声称题目已经完整可解。未登记旧图不会因为文件存在而继续进入成品。缺失输入仍遵循现有构建部分草稿机制。

## 验收关注

1. 字面图片语法出现在 code fence 或 inline code 时不能被误删；引用式图片、路径转义与 HTML 图片不能绕过。
2. 相同题干重复、不同题型出现同一图片、同页重复 occurrence 不得产生模糊绑定。
3. 题干负号/数值改变、源文件替换、图片替换或图注/坐标改变后旧批准失效。
4. 当前 source_root 的兼容回退不允许被构建用来搜索别的课程同名源文件。
5. 没有图的正常讲义保持可构建；确定绑定必须能实际输出原图，不能以全部拒绝代替功能。
