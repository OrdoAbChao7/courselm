# 期末复习讲义产品化设计

## 目标

面向基础一般、临近期末的学生，把现有 CourseLM 生成的 Obsidian 复习资料整理为结构清晰、重点突出、可用 XeLaTeX 编译为 PDF 的期末复习讲义初稿。

第一期只实现本地内容编排与 LaTeX 输出，不把讲义直接发布或自动销售，也不改变现有 NotebookLM 资料生成流程。

## 用户与质量目标

- 用户：基础一般、复习时间有限、需要快速建立知识框架并掌握常考题型的大学生。
- 结构：每个章节先说明“考什么”，再给核心概念、公式、题型、易错点和速记。
- 重点：优先保留高频知识、核心公式、标准解题步骤和代表性例题。
- 可审阅：生成内容必须保留 Markdown 中间稿和 LaTeX 源码，允许人工修改后再编译。
- 可追溯：讲义章节来自现有 Obsidian 目录中的文件，并在中间稿中保留来源文件标记。

## 第一期开关与命令

新增命令：

```text
courselm build-handout <课程名>
courselm export-handout <课程名>
```

`build-handout` 从 `output/<课程名>/md/` 读取知识结构、公式总结、题型总结和题型详解，生成：

```text
output/<课程名>/handout/
├── manuscript.md
├── main.tex
├── chapters/
└── assets/
```

`export-handout` 调用本地 XeLaTeX 编译 `main.tex`，输出：

```text
output/<课程名>/release/<课程名>-期末复习讲义.pdf
```

若系统没有 `xelatex`，命令必须给出可操作的安装/配置提示并返回运行时错误，不得假装生成 PDF。

## 内容编排

讲义顺序固定为：

1. 使用说明与考前复习策略
2. 知识结构与章节依赖
3. 核心知识与公式速查
4. 常考题型与标准解法
5. 题型详解与代表性例题
6. 高频易错点
7. 考前一页纸

第一期不重新调用 NotebookLM，不自动改写事实内容；编排器只负责合并、分组、标题清理、来源标记和模板渲染。

## LaTeX 约束

- 使用 XeLaTeX 与 `ctexart`。
- 公式保留现有 Markdown/Obsidian 的 `$...$` 与 `$$...$$` 形式并转换为 LaTeX 可编译文本。
- Markdown 标题转换为 LaTeX 章节命令。
- 普通段落、无序列表、有序列表、粗体、表格和代码块支持第一期常见语法。
- 不把 Obsidian 的 `[[链接]]` 原样输出到 PDF；转换为可读文本。
- 模板使用中文友好的默认字体配置，不绑定用户机器上的单一字体名称。

## 错误处理

- 课程目录缺失或没有现有 Obsidian 产物：返回参数/输入错误，并列出期望路径。
- 必需文档缺失：继续生成已存在部分，同时在 `manuscript.md` 顶部写入缺失项警告；命令返回运行时错误。
- LaTeX 编译失败：保留源码和完整编译日志，返回运行时错误。
- 所有输出路径必须位于配置的 `output_dir` 下。

## 非目标

- 不处理支付、用户账户、销售页、自动水印或 DRM。
- 不保证生成内容的事实正确性；事实和版权审查仍需人工完成。
- 不引入 Pandoc 等外部转换器；第一期使用项目内 Python 渲染器，降低安装成本。

## 验收标准

1. 给定包含现有四类 Obsidian Markdown 文件的课程目录，`build-handout` 返回 0，并生成 `manuscript.md`、`main.tex` 和章节文件。
2. 生成的 `main.tex` 不包含 `[[...]]`，包含 `ctexart`，并保留可识别的数学公式。
3. 题型详解按文件名稳定排序，知识结构和公式总结出现在题型前。
4. 缺失输入、无 `xelatex`、编译失败均有明确错误码和日志。
5. 所有新增逻辑有 pytest 覆盖，且不破坏现有测试。
