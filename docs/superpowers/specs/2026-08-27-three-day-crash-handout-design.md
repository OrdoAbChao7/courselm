# 考前三天冲刺讲义设计

## 1. 产品目标

CourseLM 的默认讲义面向基础薄弱、距离期末考试三天的学生。产品不追求覆盖教材全部内容，而追求以下结果：

1. 学生在第一天建立课程框架，补齐完成高频题所需的最低基础。
2. 学生在第二天掌握必背公式、题型识别信号和标准解题流程。
3. 学生在第三天通过易错诊断、最小训练集、考前速记和综合自测完成查漏补缺。
4. 每个模块都说明“学什么、为什么学、学到什么程度、完成后如何自测”。

## 2. 默认目录

讲义按以下顺序生成：

1. 封面
2. 使用说明
3. 考前三天学习规划
4. 考试地图
5. 零基础补给站
6. 一页知识骨架
7. 核心考点卡
8. 公式工具箱
9. 题型识别地图
10. 高频题型精讲（按题型动态展开）
11. 易错点诊断室
12. 最小训练集
13. 考前速记
14. 综合自测与补救路线

## 3. 三天学习路径

### 第一天：看懂课程，建立最低可用基础

- 阅读：使用说明、考试地图、零基础补给站、一页知识骨架、核心考点卡。
- 目标：能用自己的话说出课程研究对象、核心模块、模块依赖和高频考点。
- 结束检查：完成核心概念快速自测；不会的内容回到零基础补给站。

### 第二天：识别题型，形成可复现的解题流程

- 阅读：公式工具箱、题型识别地图、高频题型精讲。
- 目标：看到题目特征后能判断题型、选择公式并写出标准步骤。
- 结束检查：每类高频题至少独立完成一道基础题，不看答案复述解题模板。

### 第三天：减少失分，完成考前压缩

- 阅读：易错点诊断室、最小训练集、考前速记、综合自测与补救路线。
- 目标：定位个人薄弱点，消灭公式条件、符号单位、题型误判和步骤遗漏等可避免失分。
- 结束检查：完成综合自测，并按错误类型回查指定章节。

## 4. 模块内容契约

### 使用说明

- 提供剩余三天、一天和两小时三种阅读路线。
- 解释重要度、难度、可放弃内容和提示框标识。
- 不介绍冗长课程背景。

### 考前三天学习规划

- 每天给出学习目标、阅读章节、时间预算、具体任务、完成标准和当日自测。
- 默认每天 4 至 6 小时，总计 12 至 18 小时。
- 任务必须引用讲义中的实际章节名称。

### 考试地图

- 给出考试模块、常见题型、重要度、难度、建议投入和可获得分值。
- 明确必拿分、重点突破和时间不足可放弃内容。
- 不伪造资料中不存在的分值；无可靠试卷依据时使用相对等级。

### 零基础补给站

- 只补后续高频题型必需的数学工具、符号、单位和基本操作。
- 每个基础点采用“一句话解释、直观例子、正式表达、后续用途、30 秒自测”。

### 一页知识骨架

- 使用“基本对象 → 核心规律 → 重要公式 → 可解决问题 → 常见题型”的结构。
- 标出地基知识、依赖关系和推荐学习顺序。
- 主体保持短小，目标是形成位置感而非展开细节。

### 核心考点卡

- 每张考点卡包含：一句话理解、用途、直观解释、正式定义、核心公式、成立条件、考试问法、最小例子和自测。
- 先人话后术语，先直觉后公式，删除低频扩展和长篇证明。

### 公式工具箱

- 每个公式包含：名称、本体、人话解释、符号和单位、适用条件、触发关键词、常见变形、相似公式区别、易错点和最小计算例子。
- 末尾提供“必须背、可以推、容易混”三张清单。

### 题型识别地图

- 建立“题目特征 → 题型 → 第一反应 → 核心工具”的索引。
- 输出机器可解析的题型清单，供动态题型详解生成。
- 题型数量不超过配置中的 `max_question_types`。

### 高频题型精讲

- 每个题型包含：识别信号、本质考点、标准动作流程、每步原因、基础例题、遮答案练习、常见变式、易错步骤和答案检查。
- 解题流程必须写成“第一步做什么”的动作指令，不能只给完整答案。

### 易错点诊断室

- 按概念、题型判断、公式条件、符号单位、计算步骤、答案形式和时间管理分类。
- 使用“错误做法、错误原因、正确做法、检查方法、回看章节”的对照表。

### 最小训练集

- 用尽量少的题覆盖高频能力，分为照模板、给提示、独立完成和常见变式四轮。
- 每题标注考点、题型、难度、建议用时、卡点和回看章节。
- 题目区与答案区分离。

### 考前速记

- 压缩为知识地图、必背公式、题型识别、标准步骤、高频易错点和时间分配六个页面级模块。
- 内容可脱离正文单独打印。

### 综合自测与补救路线

- 提供短小诊断题，不追求完整模拟卷。
- 按错误表现映射到明确回看章节和补救动作。

## 5. NotebookLM 提示词策略

固定 Prompt 生成以下文件：

| Prompt ID | 输出文件 |
|---|---|
| `study_guide` | `00-使用说明.md` |
| `three_day_plan` | `01-考前三天学习规划.md` |
| `exam_map` | `02-考试地图.md` |
| `prerequisite_rescue` | `03-零基础补给站.md` |
| `knowledge_structure` | `04-一页知识骨架.md` |
| `core_exam_points` | `05-核心考点卡.md` |
| `formula_summary` | `06-公式工具箱.md` |
| `question_type_summary` | `07-题型识别地图.md` |
| `mistake_diagnostics` | `09-易错点诊断室.md` |
| `minimal_training` | `10-最小训练集.md` |
| `final_cram_sheet` | `11-考前速记.md` |
| `comprehensive_self_test` | `12-综合自测与补救路线.md` |

动态 Prompt `question_type_detail` 输出 `08-高频题型精讲/<题型名>.md`。

所有 Prompt 共用以下原则：

- 仅依据 NotebookLM 中的课程资料，不伪造考试频率、分值和原题来源。
- 面向基础薄弱学生，术语首次出现时必须解释。
- 段落短、动作明确、尽量使用表格、清单、决策树和对照结构。
- 重要内容使用 Obsidian callout：`[!IMPORTANT]`、`[!TIP]`、`[!WARNING]`、`[!CHECK]`。
- 公式继续使用标准 LaTeX，并明确符号、单位和适用条件。

## 6. 模板与课程定制

默认模板位于 `config/handout_templates/default.yaml`。

课程可在 `courses/<课程名>/handout.yaml` 覆盖：

- `title_suffix`
- `subtitle`
- `sections`（整组替换，用于修改目录与顺序）
- `latex`（与默认样式字典合并）

没有课程覆盖文件时使用默认模板。所有源文件路径必须保持在 `output/<课程>/md` 内。

## 7. LaTeX 呈现

- 封面突出课程名、“考前三天冲刺讲义”和适用人群。
- 每个一级模块默认另起一页。
- 使用统一颜色语义：蓝色核心知识、橙色高频重点、红色易错警告、绿色解题与自测、灰色补充内容。
- Obsidian callout 转换为 `tcolorbox`，并保留标题与正文。
- 页眉显示课程名和当前章节，页脚显示页码。
- 表格允许跨页，长内容不得使用无法分页的普通 `tabular`。
- 考前速记使用紧凑版式，但正文保持可读字号。

## 8. 兼容、缓存与错误处理

- 保留现有 Prompt ID `knowledge_structure`、`formula_summary`、`question_type_summary`，使旧缓存仍可识别；由于输出目标和内容契约变化，用户应使用 `--fresh` 生成新版完整讲义。
- 单个 Prompt 失败时保留已成功模块；讲义构建报告缺失模块并返回运行时错误。
- 课程模板语法错误、重复 section id、路径越界或缺失默认模板时，在触网前失败。
- 单元测试不得访问 NotebookLM；真实课程验证必须分别报告 NotebookLM 生成和本地 PDF 构建结果。

## 9. 验收标准

1. 默认模板按规定目录稳定组装所有固定模块和动态题型文件。
2. 三天学习规划明确引用讲义实际章节，并包含每天目标、任务、时间和完成标准。
3. 课程级 `handout.yaml` 能覆盖标题、目录和 LaTeX 样式。
4. NotebookLM 提示词覆盖全部模块内容契约，并保留可解析题型清单。
5. Callout、跨页表格、公式和代码块可由 XeLaTeX 编译。
6. 全量 pytest 通过；真实 `build-handout` 返回 0；具备有效 NotebookLM 登录态时，真实 `generate --fresh` 和 `export-handout` 都返回 0。
