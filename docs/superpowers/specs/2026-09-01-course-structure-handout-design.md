# 课程结构驱动复习讲义设计

## 目标

将 CourseLM 从“固定冲刺模块 + 题型动态补充”重构为“课程结构驱动的标准大学期末复习讲义”生成器。讲义服务基础薄弱、临近期末的学生，强调知识结构、题型识别、最短解法、得分点和高价值易错点，而不是内容堆积或营销化表达。

## 讲义结构

```text
绪论
动态章节：
  1.1 核心知识
  1.2 典型题型与解法
  1.3 典型例题
  1.4 本章练习
  1.5 易错点提醒
附录一 重要公式汇总
附录二 典型题型索引
附录三 考前复习提要
```

章节数量和名称来自课程资料中的结构分析，不在模板中写死。

## 生成流水线

```text
课程资料 → 课程结构 JSON → 绪论 → 逐章生成 → 三个附录
→ Markdown 文件 → manuscript.md/main.tex → PDF
```

每一个阶段使用独立缓存；单章失败可以单独重跑，已完成章节不重复调用 NotebookLM。

## 事实与来源

只依据上传资料陈述考试事实。资料明确内容正常陈述；资料支持的判断标记“[推测]”；资料没有提供的信息标记“[待确认]”。例题来源必须使用“[真题·年份]”“[老师题库]”“[老师课件]”“[作业原题]”“[教材例题]”“[改编题]”“[必要补充]”之一，不能伪造真题或频率。

## 版本与输出

新缓存位于 `raw/v2/`，不复用上一代结构缓存。Markdown 位于 `md/00-绪论.md`、`md/chapters/` 和 `md/appendix/`；讲义位于 `handout/`；PDF 位于 `release/`。LaTeX renderer 保持现有职责和 academic 布局，仅处理新目录暴露的兼容问题。

## 非目标

不引入 Web、数据库、RAG、向量库、支付、账号、SaaS 或新模型 Provider；不重新设计 PDF 排版系统。
