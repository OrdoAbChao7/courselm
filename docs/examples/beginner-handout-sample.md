# 第4章 导数的应用

## 本章路线

这一章用导数回答两个问题：函数在哪里上升或下降？哪里出现极大值或极小值？先学“用导数求极值”，再学需要更多条件的题目。开始前要会求多项式的导数。学完后，你应能独立找出极值点，并解释为什么那里确实有极值。

## 题型一：用导数求极值

### 先知道什么

导数可以告诉我们函数向上走还是向下走。对这道题，只需记住：在一个区间内导数始终为正，函数就在该区间上升；导数始终为负，函数就在该区间下降。导数等于零的点只是**候选点**，还要看它两侧的变化，不能直接认定有极值。

### 标准例题：用导数求极值

[必要补充] 求函数 $f(x)=x^2-4x+3$ 的极值。

### 跟着做

1. **求导，找到能判断升降的量。** $f'(x)=2x-4$。我们接下来要看它在不同位置的正负。

2. **找可能发生转折的位置。** 解 $f'(x)=0$，得到 $x=2$。这一步只找到了候选点，还没有证明它是极小值点。

3. **检查候选点两边。** 当 $x<2$ 时，$2x-4<0$，函数下降；当 $x>2$ 时，$2x-4>0$，函数上升。函数先降后升，所以在 $x=2$ 处有极小值。

4. **求极小值。** 将 $x=2$ 代回原函数：$f(2)=2^2-4\times2+3=-1$。因此极小值是 $-1$。

### 从题归纳

1. 看到“求极值”，先求导并解导数为零的方程。
2. 检查候选点两侧的导数符号：负变正是极小值，正变负是极大值。
3. 把极值点代回原函数，得到极值。若导数两侧没有变号，就不能仅凭导数为零下结论。

### 自己试

求 $g(x)=x^2-6x+5$ 的极值。先遮住下方解答，自己写出导数、候选点和两侧符号。

**提示：**解 $g'(x)=0$，再分别在候选点左侧和右侧选一个数检查导数。

#### 解答

$g'(x)=2x-6$，令它等于零得 $x=3$。$x<3$ 时导数为负，$x>3$ 时为正，因此在 $x=3$ 处取得极小值 $g(3)=9-18+5=-4$。容易犯的错是解出 $x=3$ 后直接写“极小值”，漏掉两侧符号判断。

## 章末过关

求 $h(x)=x^2-2x$ 的极值，并说出判断依据。若只解出了 $h'(x)=0$，请回看“题型一：用导数求极值”中的第三步。

**提示：**检查 $x=1$ 两侧的导数符号。

**解答：**$h'(x)=2x-2$，在 $x=1$ 左侧为负、右侧为正，所以 $x=1$ 是极小值点，极小值为 $h(1)=-1$。
